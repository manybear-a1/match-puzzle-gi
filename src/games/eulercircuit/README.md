# ルール

## ざっくりとしたルール
マッチ棒を一本ずつ追加していって、マッチ棒がいくつかのループに分解されたら負けです。
## ざっくりとしたルール２（わかる人向け）

オイラーグラフを作らないように辺を追加してください。グラフは単純無向グラフです。
